# 🚀 Orbital Mission Control Platform

## Global Solution 2026.1 - Engenharia de Software

Projeto desenvolvido para a disciplina de Engenharia de Software da FIAP.

A Orbital Mission Control Platform (OMCP) é uma plataforma inteligente inspirada em centros modernos de controle espacial, responsável por monitorar missões em tempo real, analisar telemetria, prever falhas operacionais e fornecer suporte à tomada de decisão em ambientes aeroespaciais críticos.

---

## Objetivo

Desenvolver uma plataforma integrada capaz de:

- Monitorar sensores distribuídos
- Receber telemetria em tempo real
- Gerar alertas críticos
- Executar análises preditivas
- Produzir relatórios operacionais
- Gerenciar usuários e permissões
- Armazenar histórico operacional
